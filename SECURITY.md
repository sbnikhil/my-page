# Security Policy

## Reporting a vulnerability

Please report privately through GitHub's
[private vulnerability reporting](https://github.com/sbnikhil/my-page/security/advisories/new)
rather than in a public issue. Include the affected URL or file, steps to
reproduce, and the impact you expect.

This is a personal project. Reports are welcome, but there is no guaranteed
response time and no bug bounty.

## Scope

This policy covers the deployed site, this repository, and its GitHub Actions
workflows. The site is a static Next.js export hosted on Vercel. It has no
accounts, stores nothing a visitor submits, and offers visitors no way to
publish content. Response headers are set in `vercel.json`.
